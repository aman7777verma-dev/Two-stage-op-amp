# Two-Stage CMOS Operational Amplifier Design Using Cadence Virtuoso

## Project Overview
This project focuses on the transistor-level design and simulation of a two-stage CMOS operational amplifier using Cadence Virtuoso. The design aims to achieve high voltage gain while maintaining suitable bandwidth and stability for analog integrated circuit applications.

## Objectives
- Design a two-stage CMOS operational amplifier at the transistor level.
- Analyze the DC operating conditions of MOSFETs.
- Evaluate open-loop voltage gain and frequency response.
- Investigate unity-gain bandwidth and phase margin.
- Analyze amplifier stability under feedback conditions.
- Understand the trade-offs between gain, bandwidth, power consumption, and stability.

## Tools and Technologies
- Cadence Virtuoso
- Cadence ADE
- Spectre Circuit Simulator
- CMOS Analog Circuit Design

## Design Methodology

### 1. Transistor-Level Circuit Design
Developed the schematic of a two-stage CMOS operational amplifier consisting of an input differential stage, biasing circuitry, and a second gain stage.

### 2. DC Operating Point Analysis
Analyzed transistor bias conditions and operating regions to verify proper circuit operation.

### 3. AC Frequency Response Analysis
Performed AC analysis to study the amplifier's voltage gain and phase response over a range of frequencies.

### 4. Gain and Bandwidth Evaluation
Evaluated the low-frequency voltage gain and unity-gain bandwidth to understand the amplifier's performance.

### 5. Stability Analysis
Examined phase margin and frequency response to assess the stability of the amplifier under feedback operation.

## Performance Evaluation

The design is evaluated using the following parameters:

| Parameter | Description |
|---|---|
| DC Gain | Open-loop voltage amplification |
| Unity-Gain Bandwidth | Frequency at which the open-loop gain reaches unity |
| Phase Margin | Indicator of feedback stability |
| Power Consumption | Power drawn from the supply |
| Slew Rate | Maximum output voltage change per unit time |
